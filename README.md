# superdeck

An Agent Skill that plans presentations with you before any slide is built: what the deck needs to say, how to hold attention, the visual concept and production plan, and only then the build and its review, with explicit approval gates between phases.

**Status:** pre-release. The skill in `skills/superdeck/` is still the original Portuguese draft and is being translated and restructured for v1.0.0. Installation instructions will be added with the first release.

Contributions are welcome; see [CONTRIBUTING.md](CONTRIBUTING.md) and [docs/design-principles.md](docs/design-principles.md).
