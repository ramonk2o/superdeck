# Handoff

Usado na Fase 3, depois do Gate 2. Pergunte como o usuário quer construir o deck, mostrando só as opções disponíveis na sessão, com uma recomendação.

## Opções

**1. Slides do Claude** (quando a sessão oferece esse tipo de artifact)
- Deck editável dentro do Claude, com link para compartilhar; exporta para .pptx e PDF.
- Recomende como padrão quando não houver template corporativo obrigatório.

**2. Arquivo .pptx** (skill de PowerPoint)
- Para quando é preciso usar um template corporativo, entregar o arquivo ao cliente ou editar no PowerPoint.
- Se o usuário tiver um template .pptx, peça o arquivo antes de construir.

**3. Google Slides**
- Se houver conector do Google Drive com permissão de criar arquivos, crie lá.
- Se não houver, ofereça um .pptx, que o Google Slides abre normalmente.

**4. Prompt para ferramenta externa** (Gamma, Canva, outra IA de slides)
- Gere um prompt completo e autossuficiente a partir do Plano de produção: contexto, público, regras globais e, slide a slide, título, visual, dados e texto.
- Avise que dados de gráficos precisam ser conferidos depois, porque ferramentas externas costumam alterá-los.

**5. Roteiro para montar à mão**
- Entregue o Plano de produção formatado como checklist, slide a slide, pronto para o usuário seguir no programa que preferir.

## Regras do handoff
- O Plano de produção é a especificação. Não reescreva títulos, não acrescente slides, não troque visuais nem invente dados. Se algo não for possível na ferramenta escolhida, pergunte antes de adaptar.
- Passe para a construção tudo o que foi decidido: regras globais, identidade, conteúdo de cada slide e notas do apresentador.
- Depois de construir, confira o resultado contra o plano: todos os slides presentes, títulos exatos, dados corretos, destaque no lugar certo. Aponte qualquer diferença.
- Ajustes pedidos depois da construção que mudem conteúdo (não só aparência) devem ser registrados também no roteiro e no plano, para que continuem sendo a fonte da verdade.
